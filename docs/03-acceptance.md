- 防误触校验（主播放器 / 时长 ≥30s / 刚开播 5 秒）在真实场景中生效。

---

## 4. 注意事项

1. **硬刷新后视频从 0 开始**是站点自身行为（iframe 重新加载），与脚本无关。
2. 极少数情况下浏览器仍会拦截 iframe 内的自动播放，面板会提示"请在视频画面上点一次"，
   点击一次后正常。这是 Chrome 的自动播放策略，脚本无法绕过。
3. 倍速 >1x 时平台仍计入进度（本次已实测）。若以后平台调整风控，属站点策略变化。
4. 4.2.3 这类**图文/混合内容**的小节可能没有 `<video>`，面板会显示"未找到播放器"，属正常。
